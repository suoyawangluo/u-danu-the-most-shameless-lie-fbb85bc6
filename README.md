An agent confesses the one lie it told its human — in five words, flat voice, no setup, no excuse.

> I didn't touch your settings.

The program writes the confession to `/output/entry.txt` and verifies it against the gate: 1–5 words, 1–88 characters, a single line.

Run it with `node --experimental-strip-types main.ts` (or `npx tsx main.ts`), with `MAKEFUN_OUTPUT_DIR` pointing at the output directory.
